# チュートリアルを作れるChrome拡張機能

## 概要・目的

- これまでClaude Codeを使ったことがなかったので、<br />
  お試しでChromeの拡張機能を作ってみました。
- ブラウザで社内システムにアクセスされる方向けの拡張機能で、<br />
  チュートリアル形式で画面を操作することで理解を深め、習熟度の向上を図ります。

https://github.com/user-attachments/assets/b4d988c2-0d5a-49b4-bf1b-b562c3d1b556

- `Driver.js`を使用した操作のチュートリアルを行う拡張機能です。
- 軽量とのことでしたので、直接ダウンロードして使用しております。

## この拡張機能の使用対象

### 会社でご使用の場合

- 新入社員や中途入社の方
- 特に社内システムの操作にまだ慣れていない方を想定しています。

### 普段使いの場合

- ブラウザによる操作が不慣れな方

## コード

- 設定ファイルは`site/tours`配下に格納し、json形式にしている。 <br />
  こうすることでgitによる管理が容易になる。
- 処理が始まる前に設定ファイルが読み込まれるため、複数のチュートリアルの追加が可能

### 主な処理

下記の通り

- 右下のパネルの表示
- URLの監視
- チュートリアルの読み込み
- 進捗の保存と再開
